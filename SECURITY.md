# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting:

https://github.com/Packmoat/packmoat/security/advisories/new

This is the only way to report one. Do not open a public issue, pull request or discussion about a security problem.

Include what you found, how to reproduce it, and the commit you tested.

## What happens next

We acknowledge your report within 5 business days, keep you informed while we work on a fix, and credit you in the advisory unless you ask us not to.

## Supported versions

Only the latest `main` branch, and images built from it, receives security fixes. To get a fix, upgrade to the latest `main` (see "Upgrades and rollback" in [docs/self-hosting.md](docs/self-hosting.md)).
